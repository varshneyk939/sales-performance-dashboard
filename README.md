# 📊 Sales Performance Dashboard

## 📌 Project Overview

This project is an interactive **Sales Performance Dashboard** created using **Microsoft Power BI**.

The dashboard provides a clear overview of sales performance and allows users to analyze sales across different time periods, categories, regions, and sub-categories.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Data Visualization
- Data Analysis

## 📈 Key Performance Indicators

The dashboard includes the following KPIs:

- Total Products
- Total Customers
- Total Orders
- Total Sales

## 📊 Dashboard Analysis

The dashboard provides insights into:

- **Sales by Month** – Analyze monthly sales trends.
- **Sales by Category** – Compare sales across Technology, Furniture, and Office Supplies.
- **Sales by Region** – Identify regional sales performance.
- **Sales by Sub-Category** – Compare performance of individual product sub-categories.

## 🎛️ Interactive Filters

Users can filter the dashboard using:

- Year
- Segment
- Region
- Category

These filters allow users to explore the data dynamically.

## 🎯 Project Objective

The main objective of this project is to transform raw sales data into an interactive and easy-to-understand dashboard that can help identify sales trends, high-performing categories, regions, and products.
